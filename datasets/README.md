# Financial test datasets

User-supplied copies, preserved without modification:

- `McDonalds_Financial_Statements.csv`
- `Tesla_Financial_Report.xlsx`

Upload a file through SureCount's workspace to test it; committing these files does not automatically load them into the running application's database.

Example questions: "What is the growth in revenue between 2002 and 2022?" for McDonald's, or "What is the revenue made in the last quarter?" for Tesla. Figures retain the source dataset's units.
